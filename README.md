
# **Rust Tool For Geometry Dash**
This crate is tool for writing code that gonna generate into blocks for GD level.

This crate useful for:
- Repeting and precise work
- Making some prebaked calculations
- When Build Helper doesnt really helps

You can learn how to use this crate in LEARN.md and examples folder

In future i planning to add:
- Identifiers - they are already exist in files but do nothing. i want them to add functionality to name some ID's under a variable.
- Functionality to read already decoded level - you will able to scan through your level and do something with blocks. for example delete every block thats have group of 1.
- More support for special objects and triggers.
